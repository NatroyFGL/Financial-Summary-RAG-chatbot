How an answer is made

  1. Rewrite. GPT-4o-mini turns your question into four search queries (RAG-Fusion).
  2. Search. Each query searches a FAISS index of the PDF embedded with text-embedding-3-large. The four result lists are merged with Reciprocal Rank Fusion.
  3. Route. The question is compared with two personas: an analyst for exact figures (METRICS) or an advisor for plain-language summaries (SUMMARY).
  4. Pick a model. Figures go to GPT-4o-mini. Summaries go to the open-source Qwen2.5-7B on Hugging Face, with GPT-4o-mini as an automatic fallback.
  5. Answer. The model may only use the retrieved passages and must cite the page, or reply that it doesn't know.

The command-line version also logs each run's settings, route, model and answer to MLflow.
